# 문제 3 — 종합해양과학기지 유의파고 단기 예측

## 1. 요약

- 최종 제출 답안 `submission_p3_v5.csv`의 Public RMSE는 `0.571098m`, 점수는 `24.269222`다.
- 배포된 `train_wave.csv`, `train_atmos.csv`, `test_context.parquet`, `test_index.csv`만 사용한다.
- 외부 관측·재분석·예보 자료와 사전학습 가중치를 사용하지 않는다.
- ExtraTrees와 LightGBM을 실행할 때 처음부터 학습한다.
- 각 평가 사례는 동일한 `case_id`의 과거 48시간만 사용한다.
- 중간 pickle, OOF 파일, 체크포인트에 의존하지 않는다.
- 일반 CPU 환경의 최종 학습·예측 시간은 약 220초로 6시간 제한 이내다.

## 2. 실행

```bash
pip install -r requirements.txt
python run_p3.py --data-dir <P3_wave_forecast 폴더> --output submission_p3_v5.csv
```

`P3_wave_forecast` 폴더에는 배포된 다음 네 파일이 있어야 한다.

- `train_wave.csv`
- `train_atmos.csv`
- `test_context.parquet`
- `test_index.csv`

실행 종료 전에 코드가 열 순서, 행 수, 키 순서, 유한값 및 `0<=hs_pred<=30` 범위를 검사한다. 실행 환경은 `VERSIONS.txt`를 참고한다.

## 3. 모델 설계

### 3.1 인과적 특징

학습자료를 정점별 10분 격자로 정렬한다. 파랑 관측은 20분 간격이므로 파랑 시차는 관측 가능한 20분 배수만 사용한다. 현재 상태와 최대 48시간의 시차, 이동평균·표준편차·최솟값·최댓값, 최근 변화율과 상승·하강 국면을 만든다.

풍향과 파향은 사인·코사인 성분으로 변환한다. 풍속, 돌풍, 기압, 기온, 습도의 시차·이동통계와 풍향-파향 상대 성분도 사용한다. 테스트 특징은 각 `case_id` 그룹 안에서만 계산한다.

### 3.2 목표값과 모델

리드별 목표값은 다음 로그비율이다.

```text
y_h = log(hs_(t+h) / hs_t),  h in {3, 6, 9, 12, 18, 24}
```

로그비율은 파고 성장·감쇠를 상대 크기로 표현하고 예측 파고를 양수로 유지한다. 각 리드마다 ExtraTrees를 학습한다. +3h, +6h, +9h에는 LightGBM을 25% 혼합하며 +12h, +18h, +24h에는 ExtraTrees만 사용한다. 마지막으로 인접 리드 예측을 20% 평활한다.

### 3.3 표본 가중

배포된 `test_index.csv`에서 정점별 독립 사례 비중을 실행 중 계산한다. 학습자료는 각 정점이 이 비중을 갖도록 균등 가중한다. 현재 배포본의 사례 수는 G-ORS 70, I-ORS 70, S-ORS 60이다.

## 4. 모델 선택

앙상블 비중과 리드별 모델은 배포 학습자료의 교차검증 OOF 예측으로 선택했다.

- 두 개의 시간 순서 전진 검증
- 세 개의 비연속 계절 블록 검증
- 검증 사례는 동일 정점에서 78시간 간격인 평가 구조를 모사해 가중
- 혼합비 후보는 `0, 0.25, 0.50, 0.75, 1.00`의 성긴 격자

두 검증 방식이 함께 지지한 장기 리드 변경만 최종 모델에 반영했다. 서로 반대 방향을 선택한 지속성 수축·확장과 역지수 목표 변환은 제외했다. 리더보드 반환 점수는 혼합비나 모델 파라미터의 목적함수로 사용하지 않았다.
